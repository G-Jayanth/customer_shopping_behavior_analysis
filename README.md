# customer_shopping_behavior_analysis
Customer Shopping Behavior Analysis — an end-to-end retail analytics project that cleans 3,900 customer records (18 columns, 37 missing review ratings filled with category medians) in Python and pandas, engineers age groups and purchase-frequency features, loads the prepared data into MySQL to answer 10 business questions covering revenue by gender and age group, discount users, top-rated products, shipping, subscriptions, loyalty segments, and top products per category, then visualizes the patterns in a Power BI dashboard — with documented limitations and segment-level recommendations, built using Python, SQLAlchemy, MySQL, and Power BI.
